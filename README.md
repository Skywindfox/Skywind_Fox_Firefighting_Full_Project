# 智能楼宇消防系统

> 省级大学生创新创业训练计划项目 · 两人合作
>
> 一块低成本嵌入式板卡，能不能替代封闭的楼宇消防控制器？

**当前状态**：控制端界面已能在开发板上跑通，探测端固件开发中。

---

## 这个课题要解决什么

楼宇消防的「**感知 → 判断 → 报警 / 联动**」链路，现在大多靠孤立的独立式探测器加人工巡检：
信息不汇总、报警靠现场喇叭和电话、控制器与值班界面往往是成套采购的封闭设备。

这个项目要验证的是：**通用 Linux + 开源图形库，能不能承担同样的事**。

- **感知**：把楼内消防状态量（开关量传感器、按键）接进控制器，持续采集
- **判断**：本地按预设规则判定火警与故障，不依赖云端往返时延
- **报警 / 联动**：驱动声光报警、指示与设备联动，触摸屏上可直接查看与手动干预

断网、断电恢复后仍需独立报警 —— 这是消防场景的底线要求，也是本项目"本地闭环"的技术核心。
